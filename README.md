# Team Task Manager

A premium, full-stack task management application with role-based access control and modern glassmorphic design.

## Features
- **Role-Based Status Tracking**: Members can mark tasks as `in-review`, but only Admins can mark them as `done`.
- **Premium UI**: Dark mode design system with glassmorphism and smooth animations.
- **Visual Analytics**: Interactive dashboard with real-time statistics.

## Tech Stack
- **Frontend**: React, Vite, Axios, React Router.
- **Backend**: Node.js, Express, MongoDB, Mongoose.
- **Auth**: JWT, Bcrypt.

## Setup
1. Clone the repo.
2. Install dependencies:
   - `cd backend && npm install`
   - `cd frontend && npm install`
3. Configure `.env` files.
4. Run: `npm run dev` in both directories.
